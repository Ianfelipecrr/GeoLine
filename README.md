# GeoLine

Sistema desenvolvido em Python para construção,
análise e visualização de equações de retas no R² e R³.

## Funcionalidades

- Construção de retas no R² e R³.
- Equações vetoriais e paramétricas.
- Equações simétricas.
- Equação reduzida no R², quando aplicável.
- Análise de relações entre retas.
- Visualização gráfica 2D e 3D.

## Tecnologias

- Python
- Matplotlib
- Tkinter
